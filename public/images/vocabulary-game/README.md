# Ilustrações do jogo de vocabulário

Imagens geradas individualmente com IA pelo gerador integrado e otimizadas em WebP, 640 × 640 pixels, para o jogo de objetos e lugares.

Prompt base: “One square vocabulary illustration for a Mandarin quiz. Subject: [subject]. Clean softly shaded editorial illustration, recognizable subject, warm ivory background, subtle terracotta and teal accents, centered generous margins. No words, no text, no lettering, no watermark.”

Cada arquivo corresponde ao assunto de seu nome: móveis (bed, sofa, chair, wardrobe, bookshelf, window, table, door); cômodos (kitchen, living-room, bedroom, bathroom, study, shower); lugares (school, hospital, supermarket, restaurant, cinema, bookstore, park, house, mall, shop, convenience-store, market, stationery-store, flower-shop); objetos (book, pen, phone, computer, laptop, television); alimentos e bebidas (apple, noodles, dumplings, vegetables, baozi, rice, milk, tea, fruit, water); transportes (subway, taxi, bicycle, bus, car); animais (cat, dog).

As cenas de cômodos e lojas usam interiores para distinguir os espaços. As imagens de objetos apresentam o objeto isolado. As imagens não têm legendas para preservar o desafio.
