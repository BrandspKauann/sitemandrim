# 汉语声调练习

这是我一边学习普通话、一边慢慢整理出来的练习网站。每当我学到一组新词、一个新句型或一段课本对话，我就把它加到这里，再通过听、读、跟读和录音反复练习。它不是一次做完的词典，更像一本会跟着我的学习进度一起成长的笔记本。

我的母语是巴西葡萄牙语，所以我把汉字、拼音、声调、葡萄牙语发音提示和意思放在同一个地方。这样练习时不用一直切换词典、翻译器和录音软件，也能更直接地比较自己的发音。

在线使用：[sitemandrim.vercel.app](https://sitemandrim.vercel.app/)

## 现在可以做什么

### 句子练习

- 输入汉字或拼音，查看完整汉字、带声调的拼音、葡萄牙语发音提示和巴西葡萄牙语翻译。
- 用自然速度或慢速播放普通话。
- 单次播放、循环播放，并自己设置每次重复之间的停顿时间。
- 播放时逐词突出汉字、拼音和对应的葡萄牙语意思，方便跟读。
- 关闭声音以后，突出显示仍然按照正常语音的节奏移动，可以用来独立朗读。
- 直接在网站里录音，每次最长 30 秒，最多保存三次练习，再和普通话原声比较。
- 按顺序练习课堂句子、数字、一个月中的日期、星期和月份。

### 字母和音节

- 按拼音声母和韵母的标准顺序查看音节组合。
- 单独播放一个音节，也可以连续播放整组内容。
- 自然速度和慢速都可以使用。
- 网站里保留了真实录音，可以练习 `a、o、e、i、u、ü` 的四个声调。
- 元音录音可以循环播放，也可以一边跟着录音一边录下自己的声音。

### 听力和课本对话

- 从 HSK 1 的汉字中随机出题，听发音后判断是一声、二声、三声还是四声。
- 每轮会重新组合题目，也可以慢速播放。
- 课本对话按“对话 3、对话 4……”分开显示，不会把所有内容堆在一个页面里。
- 每一句都有汉字、拼音、葡萄牙语翻译、语音、同步突出显示和录音练习。

### 声调组合

- 按 `1–1、1–2、1–3、1–4、1–轻声` 等组合练习双音节词。
- 四个声调都可以作为第一个声调，轻声也包括在练习里。
- 每组可以播放一次或循环播放，并提供慢速模式。
- 另外还有三音节词，帮助我适应更长的声调变化。

### HSK 1 主题词汇

词汇目前分为食物、动词和国籍几个主题。每个词都可以单独播放、单独循环，也可以播放整个主题。普通话读完以后，会再用葡萄牙语读出简短的意思。

词汇下面还有“真实普通话对话”。第一篇是一周生活的短故事，原声被分成 47 个句子，每句都有汉字、带声调的拼音、葡萄牙语发音提示和翻译。可以单句播放、单句循环或从头连续播放；这里的声音只保留普通话原声，葡萄牙语意思用于阅读。

“国籍”部分按照固定顺序排列：

1. 国家；
2. 这个国家的人；
3. 对应的语言。

例如：`中国 → 中国人 → 中文`、`巴西 → 巴西人 → 葡萄牙语`、`日本 → 日本人 → 日语`。英语、法语和韩语也放在各自国家的后面。

我还可以给每个词上传一张自己的图片，把图像和词义联系起来。图片按当前学习会话分开保存，上传上限为 100 MB；如果远程存储暂时不可用，浏览器会保留一个本地副本。

## 语言设计

这个项目的主要学习语言是普通话，辅助语言是巴西葡萄牙语：

- 汉字负责显示真实写法；
- 带声调的拼音负责标明标准读音；
- 葡萄牙语发音提示只是入门时的桥梁；
- 葡萄牙语翻译负责说明意思，但不会强行按照中文词序排列；
- 普通话语音和葡萄牙语语音分开选择，避免浏览器用错误的语言朗读。

## 我的练习空间

我会在不同时间打开网站学习：有时练习完整句子，有时只想反复听几个词或音节。每次打开一个新标签页，网站都会把它当作一段新的练习。这样即使家人、朋友或其他学习者同时使用，大家正在听的内容、录下的声音和选择的图片也不会混在一起。

我录下的发音只留在自己正在使用的浏览器里，不会公开显示给别人。为词汇选择的图片也属于自己的练习空间，所以我可以放心地用熟悉的照片建立联想。

页面右下角的计时器帮我了解自己真正花了多少时间学习。我可以看到这一次练了多久、今天累计了多久，以及时间主要用在哪一部分。只有网站页面正在眼前并且浏览器处于使用状态时才会计时；切换标签页、最小化浏览器或使用其他程序时都会自动暂停。

## 使用的技术

- Next.js 16
- React 19
- TypeScript
- CSS Modules 和全局 CSS
- Web Speech API（普通话和葡萄牙语朗读）
- MediaRecorder API（麦克风录音）
- IndexedDB 和 Session Storage（本地练习数据）
- Cloudflare R2（词汇图片）
- Vinext、Vite 和 Cloudflare Workers（网站构建与运行）

## 本地运行

需要 Node.js 22.13 或更新版本。

```bash
npm install
npm run dev
```

然后打开 [http://localhost:3000](http://localhost:3000)。

检查和构建：

```bash
npm run lint
npm run build
npm run sites:build
```

## 我为什么做这个项目

普通话最难的地方之一，是看懂拼音以后仍然不一定能听出声调，也不一定能把声音稳定地模仿出来。我想要的不是一个只显示答案的页面，而是一个可以反复听、放慢、暂停、录音和比较的练习空间。

这里的内容不会一次整理完。我今天学会一个词，明天读到一段新对话，就会把它们放进合适的练习里。这个网站会和我的普通话一起慢慢变得更完整，也记录下我从听不清声调到敢于开口表达的过程。
